# TRACK-E：台灣村里模式（7,748 村里｜分縣市按需載入＋階層作答）

- **Track ID**：`TRACK-E`
- **預估難度**：★★★★☆（全專案工程難度最高：含離線圖資壓縮切檔管線、`file://` 相容的按需腳本載入、7,748 筆效能防卡頓、大量重名消歧義與罕見字正規化）
- **前置依賴**：無（純台灣專屬擴充，可獨立於 `TRACK-M0` 實作）

---

## 1. 為什麼不能直接硬塞現有 368 鄉鎮流程？

1. **圖資體積龐大**：內政部國土測繪中心（NLSC）全台村里界（約 7,748 筆）原始 Shapefile 轉 GeoJSON 達 80～150 MB，整包載入會直接撐爆手機瀏覽器記憶體。
2. **極高重名率**：光「中正里、中山里、民生里、仁愛里、和平里、復興里」全台就各出現數十次，無法像休閒模式單靠打兩個字解鎖。
3. **面積極小**：都會區單一里常僅 `0.1～0.3 km²`（例如新北永和區 62 個里擠在 5.7 km²），純向量黑底完全無法辨認位置，**必須搭配衛星／街道或明確標示所屬鄉鎮輪廓**。
4. **台灣村里罕見字陷阱（極容易遺漏！）**：
   - 台灣村里名含大量難打異體字／CJK Ext-B 罕見字（例如：`廍`［如台南安南四草/彰化埔鹽番婆/台中北屯廍子里］、`坔`［嘉義鹿草竹山/台南柳營重溪/高雄仁武烏林等坔埔］、`磜`［屏東高樹新南/內埔］、`𥕢`、`萡`［雲林口湖萡子寮］、`寮/藔`、`峰/峯`、`台/臺`、`裡/里`、`崙/侖`、`腳/脚`、`灣/湾`）。
   - 若不建立罕見字別名表（允許玩家輸入常見替代字，例如 `部子` 對應 `廍子`、`地埔` 對應 `坔埔`），玩家會因輸入法打不出來而永遠卡關！

## 2. 離線圖資切檔管線與 `file://` 相容按需載入（關鍵設計！）

> **⚠️ 嚴禁使用 `fetch("./data/villages/65000.topo.json")`！**
> 本專案 `AGENTS.md` 規定必須支援雙擊 `index.html`（`file://` 協定），本地 `fetch()` 會直接被瀏覽器 CORS 阻擋。

### 正確架構：22 個按需動態 `<script>` 縣市包 + 1 個輕量索引
1. **離線建置腳本（新增 `scripts/build_villages.sh` 或 `.py`）**：
   - 輸入：內政部國土測繪中心開放資料《村(里)界(TWD97經緯度)》Shapefile（或已驗證之最新開放版）。
   - 使用 `mapshaper` 依 `COUNTYCODE` 拆成 **22 個獨立縣市檔**，各檔以 Visvalingam 演算法簡化（如 `-simplify 12% keep-shapes`）並轉為 TopoJSON（每檔壓縮至 **60～350 KB**）。
   - 產出格式為 **JSONP 風格的純 JS 檔**，存放於 `data/villages/`：
     - `data/villages/village-index.js`（< 220 KB）：全台 ~7,748 筆輕量索引 `[id, countyCode, countyName, townName, villageName, lat, lng, aliases]`（**不含幾何座標**），呼叫 `window.__registerVillageIndex(data)`。
     - `data/villages/v_65000.js` … 共 22 檔：每檔僅含該縣市村里 TopoJSON，呼叫 `window.__registerVillageCountyTopo("65000", topoObj)`。
2. **前端按需載入器 (`js/village-engine.js`)**：
   - 首頁啟動時**完全不載入**任何村里檔案（0 KB 初始負擔！）。
   - 僅當玩家進入「🏘️ 村里挑戰模式」時，透過動態建立 `<script src="data/villages/village-index.js">` 載入索引，並只載入**當前選中縣市（或當前題目所屬縣市）**的 `v_<countyCode>.js`（已載入者快取於記憶體 `Map`）。
   - 此機制於 **`file://` 本地雙擊** 與 **GitHub Pages HTTPS** 皆 100% 正常運作！

## 3. 玩法設計（把地獄模式變成爆紅在地玩法）

### 子模式 A：在地挑戰（自選單一鄉鎮 / 自選單一縣市）⭐ 分享擴散力最高
- 玩家先選一個縣市，再選一個鄉鎮市區（例如：「新北市 板橋區 126 里挑戰」、「臺北市 大安區 53 里挑戰」）。
- **體驗優化**：
  - 只載入該 1 個縣市檔案並僅渲染該鄉鎮的村里多邊形（數十至百餘個 Polygon，60 FPS 絲滑無卡頓！）。
  - 自動鎖定前綴為該縣市＋鄉鎮（玩家只需輸入 `光復` 或 `光復里`，免重複打 `新北市板橋區`）。
  - 支援「自由輸入全部解鎖」與「隨機抽一里猜名（搭衛星/街道底圖）」。
  - 結算卡顯示專屬鄉鎮徽章（例：`板橋區里長伯 126/126`）。

### 子模式 B：全台 7,748 村里隨機地獄模式（階層三段式作答）
- **效能鐵律**：**絕不一次渲染 7,748 個多邊形！** 每回合從 `village-index` 抽出 1 題 ➔ 按需載入該題所屬 1 個縣市的 TopoJSON ➔ 僅渲染該縣市／該鄉鎮輪廓＋高亮目標村里多邊形，並自動 `fitBounds` 搭衛星或地形底圖（可切換縮放遠景輔助定位）。
- **階層三段式作答（跳過「省」，直接從縣市開始！）**：
  - 第一段：猜 **縣市**（答對得 **20%**，解鎖並顯示該縣市邊界）
  - 第二段：猜 **鄉鎮市區**（答對再得 **30%**，解鎖並顯示該鄉鎮邊界）
  - 第三段：猜 **村里名**（答對再得 **50%**，累計 100% 滿分；支援省略「村/里」後綴的休閒選項與嚴格後綴選項）
  - 也支援高手直接一次輸入全名（如 `彰化縣芳苑鄉路上村`）直接秒殺 100%！

## 5. 驗收標準（Acceptance Criteria）

1. [ ] 未進入村里模式時，首頁載入 0 個村里檔案，記憶體與載入時間無任何增加。
2. [ ] 進入「單鄉鎮在地挑戰」（例如任意選 1 個鄉鎮），僅動態載入該縣市 1 份 `.js` 檔，畫面 60 FPS 流暢，於 `file://` 與 HTTP 皆可正常開啟。
3. [ ] 進入「全台村里隨機模式」，每題依序支援「縣市 (20%) → 鄉鎮 (30%) → 村里 (50%)」部分計分，亦可一次打完整三層名稱直接拿 100%。
4. [ ] 至少覆蓋常見台灣村里罕見字與異體字（`廍/部`、`坔/地`、`萡/箔`、`台/臺`、`峰/峯`、`寮/藔`）且通過確定性測試。
5. [ ] 離開村里模式後，`villageLayerGroup` 清空且原本 368 鄉鎮地圖完全復原；既有 `tests/` 全數通過。
