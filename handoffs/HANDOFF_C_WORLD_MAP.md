# TRACK-C：世界地圖包（猜國家 / World Countries）

- **Track ID**：`TRACK-C`
- **預估難度**：★★★☆☆（原估 ★★☆☆☆；技術門檻中等，但 **195 國繁中/簡中/台灣官方譯名/俗稱/英文別名校對**、**微型國家熱區**、**跨 180° 經線與海外領土 bbox** 屬於高細節工時項目，實測 3 顆星）
- **前置依賴**：**`TRACK-M0`**（或獨立姊妹 Repo 的 `MapPack` 核心）
- **推薦搭配**：與 `TRACK-B`（給國名標座標，`pinDropScaleKm = 1500`）與 `TRACK-A`（夜間燈火看世界超級震撼！）絕配。

## 1. 國家收錄基準與資料結構

- **檔案路徑**：`data/packs/world-countries-pack.js`（採按需動態 `<script>` 載入，目標體積 **< 450 KB**，註冊至 `window.GEOMASTER_PACKS["world_countries"]`）。
- **圖資來源**：Natural Earth `ne_50m_admin_0_countries`（或 `110m` 補微型國點位），轉 TopoJSON 並量化精簡。
- **國家名單透明基準（於 UI 明確標註）**：
  - **193 個聯合國會員國 + 2 個聯合國觀察員（梵蒂岡、巴勒斯坦）+ 台灣 = 196 國**（另提供「標準版：排除極微型島國/城邦」vs「完整 196 國」濾鏡開關）。
- **大洲分區篩選 (`regionFilters`)**：
  - 亞洲、歐洲、非洲、北美洲（含中美洲與加勒比海）、南美洲、大洋洲。

## 2. 四大必處理技術坑點

### 坑點 1：台灣繁體中文譯名＋兩岸用語＋英文＋縮寫別名表（最重要！）
台灣玩家習慣與中國大陸譯名差異極大，**必須建立完整 `aliases` 並做 0 碰撞測試**：
- 兩岸常見差異範例（皆須接受，顯示名稱以台灣外交部慣用繁中為主）：
  - `紐西蘭 / 新西蘭 / New Zealand / NZ`
  - `南韓 / 韓國 / 大韓民國 / South Korea / Korea`（與 `北韓 / 朝鮮 / North Korea` 明確區隔，單輸入 `韓國` 預設對應南韓）
  - `沙烏地阿拉伯 / 沙特阿拉伯 / 沙特 / Saudi Arabia`
  - `阿拉伯聯合大公國 / 阿聯酋 / 阿聯 / UAE`
  - `荷蘭 / 尼德蘭 / Netherlands`
  - `瑞士 / Switzerland` vs `瑞典 / Sweden`（嚴防拼寫容錯誤判）
  - `澳洲 / 澳大利亞 / Australia`
  - `英國 / 聯合王國 / 大不列顛 / UK / United Kingdom`
  - `美國 / 美利堅合眾國 / USA / US / United States`
  - `史瓦帝尼 / 史瓦濟蘭 / Eswatini`、`北馬其頓 / 馬其頓`、`捷克 / 捷克共和國`、`寮國 / 老撾`、`汶萊 / 文萊`、`克羅埃西亞 / 克羅地亞`、`波士尼亞與赫塞哥維納 / 波黑 / 波赫`、`剛果民主共和國 / 民主剛果 / 剛果(金)` vs `剛果共和國 / 剛果(布)`！
- 正規化規則：忽略大小寫、空格、連字號、括號、繁簡轉換（`台/臺`、`國/国`、`亞/亚`、`爾/尔`、`灣/湾`）。

### 坑點 2：微型國家（Microstates）看不見、點不到
- 梵蒂岡、摩納哥、聖馬利諾、列支敦斯登、安道爾、馬爾他、新加坡、巴林、馬爾地夫、諾魯、吐瓦魯、帛琉、馬紹爾群島、聖克里斯多福及尼維斯等約 20+ 國，在 `110m`/`50m` 世界地圖上甚至沒有多邊形或小於 1px。
- **必做解法**：
  - 凡面積小於門檻（如 `< 2,500 km²`）或在 TopoJSON 中無多邊形的國家，統一於資料標記 `isMicrostate: true` 並附精準首都/領土經緯度 `(lat, lng)`。
  - 地圖渲染時繪製**可點擊圓點熱區 (`L.circleMarker`，半徑 5–7px，帶白色微光外框)**，提供「隱藏/顯示微型國圓點」或「標準版（排除微型國）vs 完整 196 國」切換開關。

### 坑點 3：海外領土與跨 180° 國際換日線（Antimeridian）
- **海外領土 bbox 爆炸**：
  - **法國**：含南美洲法屬圭亞那與印度洋/太平洋島嶼，整包 bbox 跨半個地球！
  - **美國**：含阿拉斯加、夏威夷、關島。
  - **荷蘭**：含加勒比海荷屬島嶼；**丹麥**含格陵蘭（格陵蘭是否併入丹麥或獨立標示需在資料集一致定義，建議於說明註明）。
  - **解法**：套用與 `TRACK-A` 相同的 `computeMainPolygonBounds()`（或對 FR/US/NL/ES/PT/NZ/AU 明訂本土 `mainBounds`），確保隨機抽題與衛星縮放聚焦於本土！
- **跨 180° 經線繪圖撕裂**：
  - **俄羅斯（楚科奇半島）、斐濟、吉里巴斯、美國（阿留申群島）** 跨越 `±180°` 經線，若 TopoJSON 未先於 `±180°` 切割，Leaflet 會畫出橫貫整個世界地圖的水平長條錯誤線！
  - 建置腳本（`mapshaper`）須於轉換前確認圖資已正確切分日界線（Natural Earth 原生已切分，勿用錯誤工具合併），且世界地圖設定 `worldCopyJump: true`、`maxBounds: [[-85, -195], [85, 195]]`、`minZoom: 2`。

### 坑點 4：世界地圖底圖投影與無字底圖
- Leaflet 預設為 Web Mercator (`EPSG:3857`)，極區（南極洲、格陵蘭）面積視覺放大屬正常現象；**請排除南極洲於答題多邊形外**（僅作背景或隱藏）。
- 標座標與衛星模式沿用 Esri `World_Imagery` / `World_Terrain_Base` / NASA `VIIRS_Black_Marble` 皆原生覆蓋全球！
